# Hey, I'm Chirayu

> Work with optimism, hope for the best.

I'm a computer engineering student in Mumbai (graduating 2027) and a software engineer intern at Dabby, the startup under Datalis. At Dabby I build an AI financial automation platform: the part that turns messy LLM output into clean ledger data, and the live reports on top of it.

I spend most of my time on backends, but I keep finishing side projects that need a frontend too, so I end up doing both. Lately that has meant a job-application tool, a Web3 crowdfunding platform, an animal rescue app and a fact checker.

Right now I'm building **Sign Bridge**, a platform to make communication easier between sign language users and everyone else.

I try to learn one new thing every day.
